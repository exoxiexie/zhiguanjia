**401 的诊断价值**（`app.py:84~90` 的判断顺序）：
```python
token = self.headers.get("X-Proxy-Token", "")
if not PROXY_TOKEN or token != PROXY_TOKEN:      # ← 先判这个
    return 401 unauthorized
if not DEEPSEEK_API_KEY:
    return 500 server not configured: DEEPSEEK_API_KEY missing
```
`PROXY_TOKEN` 为空 → 命中**第一条** → 401。
若 `PROXY_TOKEN` 已配、只是 Key 缺 → 会返回 **500**。
⇒ **当前确诊：`PROXY_TOKEN` 未配**（`DEEPSEEK_API_KEY` 状态未知，被 401 挡住看不到）。
