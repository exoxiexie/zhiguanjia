## v1.0.21 发版：统一全站卡片宽度 + 数据页新增「对话记忆」卡片

**需求**：① 数据页经历卡片左右比顶部实名卡窄，要统一卡片宽度并「全局复用」（以发现页 / 首页智能体卡片宽度为准）；② 数据页数据卡片下方增加一张卡片「对话记忆」。

### 根因（卡片变窄）
数据页 `ListView` 外层已给 `padding: fromLTRB(12,12,12,16)`，而 `PlainGroup` 自带 `margin: horizontal 12` → 经历卡左右各缩进 24，实名卡只缩进 12，于是窄 24px。
发现页 / 首页的口径是**容器不带左右内边距、卡片自带 12** —— 这才是全站正确口径。

### 改动
- `lib/features/common/plain_group.dart`：新增全局常量 **`kCardSideMargin = 12`** 与 **`kCardMargin = EdgeInsets.symmetric(horizontal: kCardSideMargin)`**，作为全站卡片宽度的**唯一事实来源**；`PlainGroup` 默认 margin 改为 `kCardMargin`。
- `lib/features/tabs/database_tab.dart`：`ListView` 改为 `EdgeInsets.only(top: 12, bottom: 16)`（去掉左右）；两张实名认证卡补 `margin: kCardMargin`；新增 `_buildMemoryGroup()`（`Icons.forum_outlined` + `0xFF8B5CF6` + 「对话记忆」）接到已有但从未挂载的 `MemoryDetailPage(tenantId: phone)`。
- `lib/features/tabs/insight_tab.dart`、`lib/features/tabs/profile_tab.dart`：把硬编码的 `symmetric(horizontal: 12)` 换成 `kCardMargin`（**外观零变化**，纯收敛到共同来源）。
- `test/experience_test.dart`：数据页用例改为断言 4 张 `PlainGroup`（含对话记忆）；**新增 1 例**「数据页所有卡片左右内缩一致」——遍历所有 `margin == kCardMargin` 的 Container，取内层 `DecoratedBox` 量宽度，断言全部同宽且等于「屏宽 − 2×12」。

### 两个关键踩坑（很重要）
1. **`Container` 的 `getSize` 含 margin**：直接用 `tester.getSize(find.byWidget(container))` 量出来永远是整屏宽（400），量不出「卡片变窄」。必须取内层 `DecoratedBox` 才能量到卡片本体宽度。第一次写测试就栽在这里（Actual 400 vs Expected 376）。
2. **数据页 `_load()` 里不能 await 磁盘 I/O**：`MemoryStore.listAll` 是真实 dart:io（读 MD 文件），在 `AutomatedTestWidgetsFlutterBinding` 的 fake-async 区里**不会推进**，导致 `await` 卡死、`setState` 永不执行、`_loading` 一直为 true——页面降级成「4 张空卡 + 无条数」，两个用例同时挂。解法：记忆条数改为 `unawaited(_refreshMemoryCount(auth))` 单独异步刷新，首屏只等 SharedPreferences。

## 排查发现（只查未改，用户明确要求本轮不写代码）

**问题**：智能体对话（BusinessAgentPage）发送后只显示「正在思考…」，回复整段一次性弹出，不像流式；首页对话页是逐字流式。

**根因（已定位）**：`lib/features/chat/business_agent_page.dart:440` 调 `chatService.sendMessage(...)` **没传 `onDelta`**。流式的唯一开关就是 `onDelta`（契约 `chat_service.dart:209-217`）。
- 实现层 `chat_service_impl.dart:238-263` 是真 SSE 流式（`stream:true` + 逐行解析 + `onDelta?.call(..., reasoning:false)`），**能力一直在，只是这页没订阅**。
- 对照：`home_tab.dart:359`（Agent 分支）与 `home_tab.dart:403`（普通分支）**都传了 onDelta** → 真流式，逐字写入 `_streamBuffer` 并在 UI 实时渲染（`:850`）。
- BusinessAgentPage 本身没有 `_streamBuffer` / `_streamingReasoning` 等流式状态，`_isLoading` 期间只挂一个 `_ThinkingBubble`（"正在思考…"），`await` 到完整 reply 后一次 `setState` 追加整条消息 → 全文瞬现。
- **历史证据**：`git log -S "onDelta" -- lib/features/chat/business_agent_page.dart` 为空、`git log -S "agent.run"` 也为空 —— 该页自 v1.0.0 起**从未接过流式**，不是近期改坏的。用户"以前是流式"的印象来自首页对话页。

**待办（等用户指令再动手）**：给 BusinessAgentPage 补流式 = 加流式状态（`_streamBuffer`/`_streamingReasoning`）+ `sendMessage` 传 `onDelta` + 渲染流式气泡；结束时仍要落库（与 HomeTab 一致，注意 `persistMessage` 时机）。建议抽公共流式气泡/渲染逻辑给两页共用，避免出现第二套实现。
