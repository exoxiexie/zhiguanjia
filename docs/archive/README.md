# docs/archive/ · 归档区（**默认不读**）

> ⚠️ **本目录默认不进入工作上下文。**
> 这里的文件是**当时有价值、今天已过期**的历史信息。它们被保留只为追溯脉络，
> **不得作为当前决策依据**。若与现行文档冲突，一律以现行文档为准。

## 为什么要有这个目录

项目开发中会产生大量**临时的、一次性的、碎片式的**记录（当天的排查过程、当时的决策、
已解决的临时问题）。它们在当时是关键信息，但问题解决后：

- 留在活文档里 → **污染上下文**，把过期的"待办/风险"当成当前事实（真实发生过：
  2026-10-06 记录的"凭据暴露"待办，2026-10-10 被误当作当前风险上报）
- 直接删掉 → 丢失史料，无法回溯"当时为什么这么决定"

所以：**移到这里，冻结，不读**。

## 归档规则

1. **移入时机**：一件事**已解决且有结论**后，相关的过程性记录移入本目录
   （结论本身写进 `项目台账.md` 或 `KNOWN_ISSUES.md`）
2. **冻结**：移入后**不再更新**。要更新说明它还活着 → 应留在现行区
3. **默认不读**：任何会话/助手开工时**不得**把本目录内容作为上下文
4. **例外**：仅当用户明确要求"追溯历史/看当时的脉络"时，才允许扫描；且
   **扫描出来的任何结论都必须先按当前代码/线上状态复核**，才能用于决策
5. **登记**：移入时在本文件的索引表补一行（时间 + 主题 + 已迁往何处）
